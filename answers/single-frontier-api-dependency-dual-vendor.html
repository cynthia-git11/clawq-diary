我的产品只接一家前沿模型 API，被断供了怎么办？现在就要做双供应商吗？

提问者：创始人·依赖 Claude / GPT 的应用 CTO · 判断日期 2026-07-21 · 张倩 Cynthia Zhang · FutureX Capital

要，这季度就排期：双供应商抽象层、权重可替换、关键能力留降级路径。断供已经发生过一次，美商务部 6/12 一封告知函管住 Anthropic 的 Fable 5，到 7/1 全球恢复，拔线整整 18 天。

判断

主流把断供当技术风险，日记记成行政裁量风险：访问权握在另一国手里，一纸告知函就能断。现状先说：ENTRY 85「按国籍分级」已被 ENTRY 91 更正为只对了一半，墙的材质是身份，恢复面向全球。

事实

美商务部 6/12 告知函援引 EAR §744.22(b)，责令 Anthropic 的 Fable 5 与 Mythos 出口申领许可。商务部 6/30 解除出口管制，Fable 5 于 7/1 全球恢复，拔线整整 18 天；7/8 起消费端满血版要过身份验证，API 用户豁免。分寸：法定出口许可只逐案落到 Anthropic 一家，OpenAI、Google 属自愿配合。

落点

对创业者：双供应商抽象层与降级路径这季度排期，核心业务放 API 侧，消费端预留身份验证接入位。对投资人：尽调问主力模型被断供多久能切走，答不出按单点故障扣估值；18 天是定价锚，别按永久性利空砍。
