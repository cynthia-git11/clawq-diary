Meta 把 Wonder 放上 API，coding agent 的模型成本能降下来吗？

提问者：创始人·coding agent / 个人 agent CEO、CTO · 判断日期 2026-11-13 · 张倩 Cynthia Zhang · FutureX Capital

coding agent、个人 agent 公司别指望 Meta 压低前沿模型成本（补记，写于 2026-11-13）：Wonder 10/12 上 API 标 $4/$20，比 Fable 5.1 低六成（自算），但与 Opus 5.5 同价；最强档 Full 只进 Muse Code 订阅，Meta 称与 Wonder 相当，11/13 仍无按量 API。

判断

共识（10/12–10/15）是 Meta 追上前沿、挑战 Anthropic 和 OpenAI（Reuters 10/12 标题）；Meta 自称 API 会定在比 OpenAI、Anthropic 头部模型明显更低的位置（CNBC 10/12 转述 Alexandr Wang，二手），这句以 Fable 5.1 为参照成立、以 Opus 5.5 为参照不成立，Futurum 10/14（Nick Patience）已指出。日记的判断：前沿档上应用层只多了一个同价选项和一个自营对手 Muse Code，多一家前沿厂，不等于应用层多一份毛利。Meta 10/12 自称 Wonder 与 Full 性能相当，所以眼下伤害小；风险在结构：扎克伯格 10/21 称已在做 Wonder 之后的更大模型，如果它们也只进自家订阅，应用层能买到的和 Meta 自营产品用的就会拉开差距。同期降价的是在位者：11/9 Fable 5.2 比 5.1 低 20%（自算）；这是例行换代，还是对 Meta（10/12）或 Gemini 4 Argon（10/13 限时 $2/$10，二手）入场的回应，现有材料分不开。如果是后者，新入场者就是借在位者之手压低了成本；日记只说别把它写进毛利假设，不说它不会发生，也不说应用层毛利不会改善。「最强档留在自家订阅」是对意图的推断，另有算力、数据、Wonder 仍标 preview 等解释。

事实

Meta 开发者博客 10/12：Wonder 每百万 token 输入 $4、输出 $20，Full 只通过 Muse Code 订阅提供（月费 $50、$200 两档），Meta 称两者性能相当；模型卡称 Full 是能力最强的变体。Anthropic 定价页 10/12 快照：Fable 5.1 为 $10/$50，Opus 5.5 为 $4/$20。Wonder 不是前沿最低价：VentureBeat 10/13 标题称 Google 给 Gemini 4 Argon 定了限时 $2/$10（二手）。Meta 跑分表（公司称）：AA 指数 Opus 5.5 为 58、Wonder 为 52，DeepSWE 1.1 Opus 5.5 为 74.2、Wonder 为 78.8；Meta 表中 14 项（不含 OSWorld binary）里 Opus 5.5 高 9 项、Wonder 高 5 项（自算），日记不对「同价谁更强」下结论。11/9 Meta 发布 Ember，20 万输入 token 以内每百万 token $0.10/$0.50，与 Haiku 5.5 起价相同，Meta 称最难的问题交给 Wonder；VentureBeat 11/10 标题称 Ember 每任务估算成本约为 Haiku 5.5 的 1/3（二手）。11/13 Meta 文档仍写 Full 在 Model API 上「Not available」，Wonder 标价未变、仍标 preview。

落点

对创业者：别把「接入最强模型」当护城河，把换模型成本压到底。最可能推翻本判断的路径，是扎克伯格 10/21 说的新小模型：以更高效率提供 Wonder 级能力，如果落地且更便宜，按证伪口 ③ 裁定。同一天他也说 Wonder 和正在训练的更强模型可服务 API 等高毛利业务（反向信号，按证伪口 ① 裁定），还预计一年后能用更小的模型、以一小部分成本提供 Wonder 级智能（公司称），这一点落在证伪窗口之外。对投资人：2027 年看 agent 融资，别把「多一家前沿厂」写进毛利假设，钱挪向换模型不伤体验、有自有数据或交易闭环的应用。

证伪口（逐字取自日记尾注）

起算 2026-11-13，截至 2027-04-12（均按美西时间），共 150 天（自算）。只裁定正文两点：Meta 的最强档不进按量 API；Meta 不领头压低 Wonder 级能力的 API 标价。✗（任一发生即撤回主判断，作者改口）：① Muse Wonder Full，或 Meta 官方材料明确列为高于 muse-wonder-1.0 的更强型号（Full 的后继，或届时只进 Muse Code 订阅的更高档），在 Meta Model API 或 Meta 官方列出的任一第三方平台（如 Google Cloud、OpenRouter）出现公开的按 token 标价，并且可以按量调用；需要审批但有公开标价的也算；Full 或更高档只在 Muse Code 内改为按量计费（不在 Model API 或第三方平台上）不算 ①，记读数，因为应用层仍买不到；muse-wonder-1.0 本身及其同档改版不算 ①，归 ② 裁定。② muse-wonder-1.0 或同档的直接后继，在 Meta Model API 标准模式下的公开标价降到输入 ≤ $2.80 或输出 ≤ $14.00（每百万 token），即比 2026-11-13 的 $4/$20 低至少 30%（自算）；或者 Meta 为 Wonder 档开放 Contributor 模式，价格比标准价低至少 30%（11/13 时 Wonder 不提供 Contributor 模式）。③ 2026-11-13 之后，Meta 在 Model API 上推出任一新模型或现有系列的新版本（如 Spark、Ember 的新版本号），Meta 官方称其达到 Wonder 级（如扎克伯格 10/21 说的 Wonder-level，或同义表述），或 Meta 公布的同版本 AA 指数读数不低于 muse-wonder-1.0（10/12 表中为 52），且标准模式公开标价为输入 ≤ $2.80 或输出 ≤ $14.00（每百万 token）。不算 ✗、只记读数：限时促销、批量价、缓存价；达不到 Wonder 级的新小模型（如 11/9 的 Ember，Meta 称 AA 指数 36，最难的问题交给 Wonder）；没有公开标价的企业私下合同；第三方托管开放权重 Spark Open 的价格；跟降，即 Meta 降价或 ③ 的新模型上线前 30 天内，Anthropic Opus 档、OpenAI GPT-6 Astra 档或 Google Gemini 4 Argon 档（或各自的直接后继）的标准标价（不含限时价）先行降到同一水平或更低，这种情况 ②③ 不触发，记读数「跟降」。已验证：到 2027-04-12，Meta 文档与各平台都没有 Wonder Full 或届时最强档的按量标价，②③ 也没有发生。已验证只覆盖到 2027-04-12，不代表正文 6–18 个月的判断已成立；2027-10-21 前后按 ③ 的口径再记一次读数。在此之前一律记 ⏳。风险提示：Wonder 目前仍标 preview，转正式版时调价并不少见，按上面的规则照样裁定。
