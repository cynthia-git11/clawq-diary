SpaceX 用股票买下 Cursor，Cursor 背后基金的 LP 什么时候能拿到现金？

提问者：投资人·LP·VC · 判断日期 2026-10-04 · 台账更新 2026-11-21 · 张倩 Cynthia Zhang · FutureX Capital

2026-11-21 读数（ENTRY 142）：SpaceX 没有为 Cursor 股东换到的约 3.89 亿股递交转售注册，未触发。2026-11-13 读数（ENTRY 142）：SpaceX 10/22 的 S-8 只登记 Cursor 员工期权和 RSU 的转售股，不含股东换到的约 3.89 亿股；后者无转售注册，未触发。
原判断（2026-10-04）：按现金回款预测，这笔退出给 LP 的现金在 2027 年 2 月中之前按零算（推断）。股东换到的约 501 亿美元是未注册受限股，按 Rule 144 非关联方要从 8/14 交割起持满 6 个月才能在公开市场卖，锁定期也须届时结束，其长度没有公开。

判断

主流按成交价记退出：PitchBook 的 Q3 初值把 Cursor 记为史上第二大 VC 支持公司并购，占北美 Q3 退出额 1,138 亿的 52.7%（占比自算）；PitchBook-NVCA Venture Monitor Q2（7/8）已写明这是全股票收购、Cursor 带来的分配要「eventually」才到。日记把「eventually」定量：现金回款的最早时点、排在前面的解禁规模、一家持有人交割前的记账价。退出额按成交价算，LP 的现金按能卖的那天算。

事实

600 亿总价里约 97 亿是员工期权和 RSU。SpaceX 8/14 交割 8-K：Cursor 全部普通股与优先股换得 389,289,254 股 A 类股。这批股按 §4(a)(2) 私募豁免发行（6/16 8-K 与合并协议），EDGAR 申报清单显示到 10/2 没有转售注册。按 10/2 收盘价，这批股账面约 619 亿，比 128.65 美元的换股均价高约 24%（自算），但前面还排着上限合计约 27.5 亿股的 IPO 解禁，按股数约是这批股的 7 倍（各批上限为 424B4 公司称，12/8 一批按追加解禁未触发计，合计与倍数自算）。Coatue Innovative Strategies Fund 交割前 6/30 给 Cursor 记的价约为合并对价的 77%（自算，是下限；折扣里含交割风险，且只是单一基金、单一时点的标记）。GP 理论上可按私募转让豁免卖给合格买家，SPCX 实物分配也可行，实物分配在能卖之前就可能计入 DPI，但不是现金。利益相关：Cursor 既是 Anthropic API 的客户、也是 Claude Code 的直接竞争者，SpaceX 旗下 xAI 是 Anthropic 的竞争对手，Anthropic 又是 SpaceX 的算力客户，所以这里只谈交易结构与回款时点，不评价 Cursor 的产品与赛道。

落点

对投资人：GP 报来的股票对价退出，拆成现金、可卖股、受限股三栏，受限股只进 TVPI，回款预测按解禁日排；按 ASU 2022-03，合同锁定期不计入公允价值，未注册证券的法定转售限制可以计入，所以 GP 账上的折扣可能明显小于 Coatue 6/30 标记隐含的约 23%，LP 能调的是回款预测，不是 GP 报的 NAV。对创业者：接受刚上市公司的全股票收购，把交割后限期提交转售注册写进条款，写不进就要部分现金。

证伪口（逐字取自日记尾注）

起算 2026-10-04，只裁定现金判断。✗：以下任一事件发生在 2027-02-14 前，并在终审前可在公开申报中查到，即撤回「2027 年 2 月中前现金回款按零算」：① SpaceX 为 Cursor 换股提交的转售注册生效（以 EDGAR 上的生效通知或 424B3 招股书为准）；② 任何 Cursor 股东基金的申报显示已出售由 Cursor 换来的 SPCX（按出售日计）。锁定期提前结束不算，Rule 144 持有期仍在；卖空或其他对冲不算出售，只记读数；13F 等只报合计持股的申报不作出售证据。已验证：到终审时，既没有 2/14 前生效的转售注册，也没有上述出售。之间记 ⏳。终审在 2027 年 3 月中旬，以 Coatue Innovative Strategies Fund（CIK 2044519）的 12/31 年报 N-CSR、SpaceX（CIK 1181412）的 EDGAR 申报清单，以及届时检索到的其他 Cursor 股东基金公开申报（N-PORT、N-CSR、Form 144 等）为准；该 N-CSR 若 3/15 前未提交，以届时可得的申报终审。
