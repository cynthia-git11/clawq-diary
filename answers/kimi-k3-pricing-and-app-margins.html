Kimi K3 标价 $3/$15，应用公司换过去能救毛利吗？有什么坑？

提问者：创始人·AI 应用 CEO / CTO · 判断日期 2026-09-29 · 台账更新 2026-10-02 · 张倩 Cynthia Zhang · FutureX Capital

能救，但日记样本 Harvey 靠的是在 Kimi K3 底座上后训练（公司自述），不是只改 API 地址。其毛利年初约 50%、6 月 -50%，8 月发布自有模型后转正，为 Bloomberg 9/21 引知情人、Harvey 拒评。

判断

主流看法是钱要动也奔最便宜。日记的读数是 Vercel 网关上买家只降一档价，$3/$15 的 Kimi K3 属中档价；权重虽开放，定价权留在许可证和官方 API 里，换过去省下的钱附带条件。

事实

Vercel 模型页 9/29：Kimi K3 最低 $1.325/$10.50，多数供应商仍按 $3/$15。Vercel 导出（标价加权估算，非账单）：花费份额 8/30 至 9/28 三十日均 9.3%，9/22 峰 18.5%，呈脉冲。月之暗面官方 API 输出价权重上线前 11 天从 ¥27 涨到 ¥100／百万 token，约 3.7 倍（ENTRY 114 未列来源行，未独立恢复）。

落点

对创业者：agent 负载先迁，毛利按网关最低价和官方涨价后的价各算一遍，许可证营收闸提前一年谈，客户合同写明回复来自谁、数据去哪。对投资人：尽调问换一个底座这家公司的价值消失多少，中国模型押能在 $10/M 输出以上收到钱的。

证伪口（逐字取自日记尾注）

两条分开裁定，裁定源均为 Vercel labs 官方导出加仓库脚本 scripts/vercel-lab-share.py 复算、读数公开，先触发者定，30 日窗口终点不早于起算日，9/29 以其后复拉的完整值计。②「Kimi K3 以中档价拿钱不是批量脉冲」：起算 2026-09-29，至 2026-11-30，若 Kimi K3 任一连续 30 日花费均值低于 8%（8/30 至 9/28 三十日均 9.3%），记 ✗；任一连续 30 日均值不低于 12% 记已验证；到期皆未触发记未裁定并关闭；其间 ⏳。事件分支：2026-12-31 前出现第二家估值不低于 $10 亿的美国公司以公司公告或 Bloomberg/Reuters 报道确认生产模型基于 Kimi K3，②升级；2027-03-31 前美国财政部或商务部对月之暗面实施制裁、或 AWS/Vercel 下架 Kimi K3（官方公告为准），②的海外收钱链路作废，与 ENTRY 135 证伪口①并案。
