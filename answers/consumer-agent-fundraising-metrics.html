消费级 agent 该拿什么指标去融资？下载量还算数吗？

提问者：创始人·消费级 agent 创始人 · 判断日期 2026-09-25 · 张倩 Cynthia Zhang · FutureX Capital

下载量不够，消费级 agent 融资该拿商家接入数和结账转化。Meta Muse 至 9/19 美区下载约 250 万、DAU 55.7 万，为第三方估算（Sensor Tower，经 CNBC、BofA 转引），Meta 零官方数。

判断

共识（JPM 9/24）把抽成看作远期变现、近期不聚焦变现。日记的分歧点：抽成就是产品本身，估值变量是商家接入数与亚马逊是否开门，所以成败看多少商家愿意接，不看 DAU。

事实

Sensor Tower 估算 Meta Muse 至 9/19 美区下载约 250 万、DAU 55.7 万，同源 DAU/下载 22%（无原帖，经 CNBC、BofA 转引）。Appfigures 9/19：前 11 天应用内净收入 2.7 万美元，只计 App Store 内购，Muse 订阅走 Stripe，不能当变现指标。亚马逊 9/20 封锁（Bloomberg 引发言人）。

落点

对创业者：融资材料把下载量换成商家接入数和结账转化，先把支付轨接上。对投资人：尽调消费级 agent 先问接了几家商家、结账走谁的支付轨，第三方下载估算只作参考。

证伪口（逐字取自日记尾注）

③「下载不值钱」的读数线（裁定源：Sensor Tower 美区 DAU 经 CNBC/BofA/Benzinga 转引，起算值 55.7 万、至 9/19；无转引时以 Apptopia 美区移动 DAU 经 TechCrunch 为后备，起算值 64.2 万、阈值按同比例换算；皆无记裁定源缺失）：至 2026-12-31 若 DAU ≥100 万且 DAU/下载 ≥30%，本条撤回；若 DAU ≤40 万，或 Meta 上调 FY26 费用指引并点名 Muse 推理成本，本条加强；其间记 ⏳。
