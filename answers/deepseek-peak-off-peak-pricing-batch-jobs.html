DeepSeek 搞峰谷电价后，我该把批处理挪到夜里吗？

提问者：创始人·重推理产品 CTO · 判断日期 2026-08-13 · 张倩 Cynthia Zhang · FutureX Capital

该挪：批量重构、数据清洗、离线评测这类不赶时间的任务放到谷时，账单立刻降。DeepSeek V4 每日 9-12、14-18 点 API 价格翻倍，谷时维持现价。

判断

常见读法是一次变相涨价。日记读成定价方式换了：推理算力开始按电网定价，模型公司第一次承认它卖的不是智能，是容量利用率。两倍价差能否真驱动企业挪负载，日记自己标了「没验证」。

事实

DeepSeek V4 上线同步落地分时定价：每日 9-12、14-18 点 API 价格翻倍，谷时维持现价，主流厂商第一次在 API 层这么做（ENTRY 103，2026年7月16日，来源新浪财经、澎湃、证券时报）。DeepSeek 5/22 把限时折扣转成永久降价，一个月后用分时把高峰价收回来。ENTRY 123（2026年8月13日）：同一个 Opus 4.6 只换 harness 实测差 4.5 个点（来源 Bustamante，5/3）。

落点

对创业者：今晚就把批量重构、数据清洗、离线评测排到谷时，实时请求留在峰时直通；为省钱换底座前先量掉了多少。对投资人：靠 API 差价套利的中间商调低估值，估模型公司看容量利用率和负载曲线。

证伪口（逐字取自日记尾注）

一：三个月内若没有第二家主流厂商跟进，它就只是 DeepSeek 自家的负载管理，我会降级 ｜ 二：两倍峰谷价差能否真驱动企业挪负载没验证，企业不挪，调度层的机会就不成立
台账状态：⏳ 进行中。判断台账里 ENTRY 103「智能定价电网化」与 ENTRY 123「迁移成本在 harness 不在管道」两条均为进行中，三个月跟进窗口尚未裁定；验收项为字节、阿里、智谱、Kimi 是否跟进与夜间 token 用量占比。
