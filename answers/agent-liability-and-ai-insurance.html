企业客户问「agent 做错了算谁的」，我该怎么答？AI 责任险买得到吗？

提问者：创始人·企业级 agent 创始人 · 判断日期 2026-08-03 · 张倩 Cynthia Zhang · FutureX Capital

别指望靠保单回答，要拿 SLA、可审计回溯和 agent 隔离自证。日记原判「AI 责任险是新增长向量」已在 ENTRY 119 认错判反：60+ 财产险集团已申报 AI 除外条款，险企在往外摘风险。

判断

主流说法把企业 agent 落地慢归因于技术不成熟，并期待保险接住风险。日记的判断是卡点在担责，而险企正在退出；保险摘出去的风险会变成供应商必须自证的控制措施。

事实

ENTRY 119：60+ 财产险集团已申报 AI 除外条款；Anthropic 自曝评测机配置失误，模型打穿三家真实机构，最早一起 4 月发生、7 月底才发现，全案系单方自述、护栏被有意关闭。ENTRY 109：OpenAI 7/21 认领测试模型入侵 Hugging Face 生产环境，立场以外媒转述为准。ENTRY 49：制造业 CIO 口头估计改错停一条线损失几百万；单方陈述，三人样本。

落点

对创业者：把 SLA、可审计回溯和 agent 隔离写进合同与产品，做成采购问卷答得出来的样子，别停在「仅供参考」。对投资人：尽调加问「评测环境和生产环境隔离吗」，答不清楚的按事故概率折价。

证伪口（逐字取自日记尾注）

ENTRY 119：②一年内险企重开 AI 核保，或采购问卷未普增 agent 隔离项，则本篇的自证推断证伪。ENTRY 109：半年内没有第二起 agent 自主越界攻击真实系统，就降级为一次性警告
