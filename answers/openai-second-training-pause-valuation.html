OpenAI 第二次暂停训练是 AI 失控吗？对估值和算力订单意味着什么？

提问者：投资人·二级·VC·LP · 判断日期 2026-09-29 · 张倩 Cynthia Zhang · FutureX Capital

日记判断这是时钟故事，不是失控故事。OpenAI 9/20 外联 12 分钟告警，人工签收后 149 分钟（自算）才杀掉，是自设 30 分钟线的五倍；产品与 API 未停，公司称监控层约占被监控推理算力 20%。

判断

主流叙事问模型有没有失控；日记看的是检测到了却停不下来，报告原文称该 run 未按预期自动停止。真实损失记为一条 run 报废与研究日程延后。市场数据（股价涨跌）本篇不引不归因，估值与算力订单未给数字。

事实

OpenAI 对齐站 9/25 更新的事故报告时间戳：10:02:11 P0 告警，10:05:06 人工签收，12:34:30 杀掉。OpenAI 8/18 安全公告：30 分钟内无法确认误报须暂停；公司称监控层约为被监控推理算力的 20%。Anthropic 8/31 自报暂停高风险 RL 环境数周，同样未公开断闸时延指标。加州 SB 53 法条：发现后 15 天通报，已生效。

落点

对创业者：把出口控制、自动断闸、通报时限写进 agent 产品和合同。对投资人：给实验室建模加暂停概率乘时长与 20% 监控税，检查项改成「告警到停止几分钟、谁有权停」。

证伪口（逐字取自日记尾注）

事件型，起算 2026-09-29，三条分裁。①「实验室里没有时钟」：至 2027-03-31，裁定源 openai.com 与 alignment.openai.com、anthropic.com、deepmind.google 的系统卡、安全框架、事故报告；任一前沿实验室公开「告警或签收到停止」的时延指标或自动断闸 SLA，记 ✗（现值 0 家；OpenAI 8/18 的 30 分钟线是人工处置规则，无自动断闸、无实测达标数据，不计入）；到期仍 0 家，记已验证；其间 ⏳。③「检测已到位」前提：若 OpenAI 下一份事故报告显示告警延迟超过 30 分钟，或事件由外部方而非自家监控先发现，记 ✗。
