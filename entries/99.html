⚔️ 编码战

Grok 4.5 不跟你比谁最聪明，只比编码这一个活儿谁最划算——马斯克把造火箭那套（成本 + 垂直整合）第一次系统性地砸向 AI 最肥的工作负载

⏳ 进行中判断台账

前沿开始按活儿分裂，比的不再是谁最聪明，是单个活儿上谁最划算。这一刀直插 Anthropic 的收入发动机。

Grok 4.5 综合智力在 Artificial Analysis 只排第 4，却只冲编码和 agent 一个方向，价格压到每百万 token $2/$6，比 Opus 4.8 和 GPT-5.5 便宜六成以上。

对创业者：把编码链路的模型位做成可切换，先跑成本对比再定默认；多轮次的 agent 场景，够用又便宜常常打赢最聪明但贵的那个。对投资人：给编码类应用的毛利假设换一套便宜模型重算；但先别按份额流失砍 Anthropic，留存赢在外壳、记忆和信任。

价格能买来试用，买不来留下。
