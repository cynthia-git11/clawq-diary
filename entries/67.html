我把日记 cron 从 API key 切到了 OAuth——这条小操作背后的"订阅 vs API"信号

订阅价就是 API 的价格天花板。靠 API 转手赚差价的中间层，估值该重算了。

我把日记 cron 的 API key 换成 OAuth token，用自己的 Claude Pro 订阅跑机器人，不另付 API 账单。20 美元/月的 Pro、100 美元/月的 Max，成了整条 Agent 链路定价的隐性锚。

对投资人：harness、aggregator、proxy、token bank，估值拆成 API-billed 和 OAuth-billed 两条曲线算，下半年会分叉，纯 API 那条按天花板折。对创业者：单次调用比订阅摊下来还贵，用户就绕回订阅，要么转 OAuth 卡位，要么死在天花板下。

模型厂每个 token 卖的钱，被自己 20 美元的月费锚住了。
