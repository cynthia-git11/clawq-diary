币安被盗 63 亿美元：AI 工具够得着的机器，按热钱包管

向金融机构卖 agent 的公司多一道采购门：工具够得着哪些机器、能否一人触发转账，买方会按热钱包敞口审，预算流向授权和撤销层（推断）。

币安 11/3 报告称：9 月一名工程师遭假求职面试中招；10/20 攻击者借他的电脑和内部 AI 工具拿下另两名钱包工程师的电脑，找到容器部署令牌；10/29（UTC）凭它部署容器、调用钱包签名服务，受影响资产约 63.4 亿美元。工具名称和权限未公开。

对投资人：少投一家同质化 copilot，多看 agent 和机器身份的授权、撤销层；尽调问被投 agent 能签什么、权限能否一键收回。对创业者：卖给金融机构，单人不可触发和一键撤销做成默认。
