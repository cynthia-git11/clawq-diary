🔓 开放即生意

今晚史上最大的开放模型落地，还开源就涨价——开放权重从来不是慈善，是一门生意

开放权重是生意，不是慈善：权重免费送，钱在下游的自营 API、订阅和本地部署上收。

月之暗面今晚放出 Kimi K3 完整权重，2.8 万亿参数，落地即史上最大；同一时刻官方 API 反而涨价，输出比 K2.6 涨约 2.1 倍。中国开源模型已占 HuggingFace 下载量 17.1%，美国 15.8%。

对创业者：这个体量自托管多数企业玩不起，最后还得回去用涨了价的云 API——别把「开源了所以便宜」写进毛利模型。对投资人：尽调换一条——换一个底座，这家公司的价值会消失多少？越接近 0 越值得投。砸得最狠的是中端任务和薄套壳，前沿仍保得住溢价。

美国把最强的锁进保险柜，中国把最强的撒向全世界。
