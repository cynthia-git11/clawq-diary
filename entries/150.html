禁令加白送，托管 DeepSeek 的高溢价撑不过一年

只靠把开源权重跑得更快收溢价的托管商要难过了，握卡、握客户的两端有机会。DeepSeek 10/20 白送推理引擎 DeepInfer 后，标官方谷时价 1.5 倍以上的托管商占比，会从 11/13 的 36% 降到 2027-10-31 的 15% 以下（推断）。

DHS 10/19 公开排除令：联邦民事机构停采、移除 DeepSeek 及基于它的第三方产品，最肯付合规溢价的客户没了（推断）。中方 10/16 起要求所列 AI 技术出口先登记，已开源的不进拟管目录。11/13 的 36 家第三方托管商里，17 家已低于官方谷时价（自算）。

对投资人：推理优化中间件和纯托管别给软件倍数，按锁住的 GPU 小时和客户合同估值。对创业者：只卖快和便宜撑不住，得握卡或握客户。

从 2026-11-13 起算，属于补记，不计入事前命中。只裁定正文这一条判断：标价不低于官方谷时价 1.5 倍的第三方托管商占比，到 2027-10-31 会降到 15% 以下。口径：数据用 OpenRouter 公开端点 API（/api/v1/models/模型名/endpoints）；模型取 DeepSeek 官方 API 中 deepseek-flash 当日对应的开放权重模型（11/13 为 V4.1-Flash-1017）；该模型没有开放权重、或它的第三方供应商不足 20 家时，改用 OpenRouter 上第三方供应商最多的 DeepSeek Flash 系列开放权重模型；该模型在 OpenRouter 上架不足 60 天时，改用上架满 60 天、第三方供应商最多的 DeepSeek Flash 系列开放权重模型；第三方供应商不含 DeepSeek 自己，也不含天际在投公司（11/13 只有 Mistral，排除它，避免作者的持仓影响裁定）；统计含自有 GPU 的云厂商和有企业合同的平台，✗ 若因它们维持溢价而触发，不事后把它们划出统计；每家取最便宜的标准档公开端点（只取 service_tier 为空、tag 不含 spot 的端点），价格取端点 API 返回的 pricing.prompt 与 pricing.completion（已扣除 OpenRouter 标注的 discount），按输入与输出 3:1 混合；基准一律用 DeepSeek 官方 API 中 deepseek-flash 当日的谷时价，输入取缓存未命中价，同样按 3:1 混合（11/13 为 0.15/0.60，即 0.2625 美元/百万 token）；裁定日官方价若高于 11/13 的水平，按 11/13 的水平算，防止官方涨价让比例被动下降；官方若不再分峰谷，用它的单一列表价；指标是报价不低于基准 1.5 倍的供应商家数占比。现值：11/13 为 36 家中的 13 家，约 36%（自算；按折前价为 18 家，约 50%），基线 JSON 已存档。✗：2027-10-31 裁定日占比仍 ≥30%，作者撤回本篇判断，并在当期条目里公开改口。已验证：占比 ≤15%，1.5 倍以上的家数少于 11/13 的 13 家（防止只靠低价新户摊薄比例过关），且按折前价（返回价 ÷（1−discount））重算，1.5 倍以上占比也 ≤15%（防止临时折扣让结果过关）。其余情形只记读数，不裁定。裁定日之前每次复看记 ⏳，只记读数。✗ 线 30% 低于现值 36%，现状不变就会触发。裁定源：2027-10-31 当日抓取并存档的 OpenRouter 端点 JSON，以及 api-docs.deepseek.com/quick_start/pricing 页面的 Wayback 存档。源缺失时：API 抓不到，用裁定日前后 7 天内的 Wayback 快照；仍然拿不到，记「源缺失，不裁定」，不顺延，不改判。不在本证伪口内：DeepSeek 是否开源 KV 缓存或负载均衡组件（SGLang 已开源同类组件，测不出本篇判断的对错）；托管商是否用 DeepInfer（无法核实）；各家托管商的份额（没有公开数据）。截至 2026-11-13，✗ 与已验证都未触发，裁定日在后。
