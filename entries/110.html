老黄发了人生第一条推特，为的是开放权重——但这封信真正的新闻在缺席名单里

分阵营别看「开源 vs 闭源」，看收入吃不吃前沿模型 API 溢价——吃得最多的三家，这次一个都没签。

25 家机构联署开放权重公开信，黄仁勋为它发了人生第一条 X 帖，OpenAI、Anthropic、Google 全部缺席。Google 本就是最大开放权重发布方之一，Meta 签了却已实质转闭源。方向也被搞反：现行管制豁免开放权重，悬着的是进口管制。

对创业者：底座压在中国开放权重上的，别做出口管制预案，做进口管制预案，迁移路径现在就备好。对投资人：给这类公司定价，风险项从「不能出去」换成「不能进来」；尽调只问一句：行政令真落地，这家公司多久能把底座换掉。

闭源的风险是不能出去，开放权重的风险是不能进来。
